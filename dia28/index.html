Afterprint

Afterprint sirve para ejecutar un código de JavaScript después de un proceso de impresión o la vista previa de una impresión. Ayuda a restaurar elementos o funcionalidades de la página que se habían modificado para la impresión.


Animationstart

Sirve para detectar y ejecutar código JavaScript en el momento exacto en que una animación CSS comienza a ejecutarse. Se dispara cuando la animación arranca.


Blur

Sirve para ejecutar una acción cuando un elemento pierde el foco en una página web. Se usa por ejemplo para validar datos, formularios al salir de un campo, mostrar mensajes de error o de ayuda, cambiar estilo de un elemento,...


Drag

Se utiliza para permite a los usuarios mover elementos en una interfaz gráfica, como organizar archivos o mover un objeto de un lugar a otro en una página web.


Keyup

Sirve para ejecutar una acción cuando el usuario suelta una tecla en un elemento, como un campo de texto. Se utiliza para realizar tareas como validar entradas en tiempo real, convertir texto a mayúsculas mientras el usuario escribe, o actualizar un contador de caracteres.


Reset

La función Reset() se utiliza para establecer el estado del evento a "no señalado" (non-signaled state).


Suspend

Sirve para manejar la interrupción en la carga de contenido multimedia (audio o video) en un navegador web.


Wheel

Se utiliza para ejecutar una función cuando el usuario desplaza la rueda del ratón o el panel táctil sobre un elemento de una página web.


Toggle

Se refiere a la funcionalidad de alternar entre dos estados u opciones diferentes, como encendido/apagado, visible/oculto o activo/inactivo, con cada interacción del usuario.


Seeked

Sirve para ejecutar una acción o función después de que el usuario o el navegador ha avanzado o retrocedido en la reproducción del contenido.


Resize

Sirve para detectar y ejecutar código cuando se redimensiona la ventana del navegador o un elemento de la página, permitiendo adaptar la interfaz de usuario de forma dinámica.


Paste

Se utiliza para detectar y gestionar cuando el usuario pega contenido (texto u otros datos) en un elemento de una página web, como un campo de texto o un área de entrada.


Loadstart

Sirve para detectar el inicio de la carga, lo que permite ejecutar código de JavaScript en ese momento, como mostrar un indicador de progreso o pre-cargar el archivo de forma asíncrona.


Cut

Se utiliza para ejecutar una acción o función cuando el usuario corta (utiliza la función "cortar") el contenido de un element
